물체를 낮게 놓으면 초반 실패가 얼마나 줄어드나

학습에서는 물체를 기본 시작 위치보다 0~10mm 위에서 놓습니다(objInitPosZHigh: 0.01). 높이 떨어진 물체가 손 안에서 구르다 기울어짐 조건에 걸려 1초도 안 돼 끝나는 경우가 많아서, 평가 때만 0~1mm 위에서 놓도록 바꿔(task.env.objInitPosZHigh=0.001) 같은 체크포인트를 다시 평가했습니다. x, y(±1.5cm)와 yaw(±180°) 랜덤화는 그대로이고, 두 평가 모두 900 env, 결정론적 행동, 물체당 300개 이상, 시작 시 길이 0 기록 제외입니다.
